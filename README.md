# Online CBT School

A Computer Based Test (CBT) platform for Excellentia Digital Academy.

Students enter their name, choose a subject, and complete a timed multiple-choice test. Questions are stored in a Supabase database, and results are saved automatically after each test.

**Live site:** https://benalee25-wq.github.io/online-cbt-school/

## Subjects available
- Mathematics
- English Language
- Biology
- Chemistry
- Physics
- Computer Studies
